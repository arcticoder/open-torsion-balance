- [ ] **`hardware/instrument/host/logger.py:198` (with `:222`) — live logging stops after one quiet second.** `main()` opens the port with `serial.Serial(a.port, timeout=1)`, and `run()` treats any empty `read()` as end of stream (`if not data: break`), so a 1 s gap in USB traffic (device reset, slow env-only stream, host hiccup) silently ends the run. Verified with a fake source whose first read returns `b""`: `run()` returned at once with zero counts.
  Steps: give `run()` an `eof_on_empty` flag (True for `--file`, False for `--port`) and keep looping on empty serial reads until Ctrl-C (`KeyboardInterrupt` → close files, print counts); add a `test_host.py` case that feeds an empty chunk between two packets and expects both packets.
